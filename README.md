# My Favorite Series: Stranger Things

## Overview
**Stranger Things** is an American science fiction horror drama television series created by the Duffer Brothers.

### Details
* **Genre:** Sci-Fi, Horror, Drama
* **Seasons:** 4
* **Platform:** Netflix

---

### Key Characters
1. **Eleven** - A young girl with psychokinetic abilities.
2. **Mike Wheeler** - A passionate and intelligent student.
3. **Dustin Henderson** - A smart, comedic member of the group.
